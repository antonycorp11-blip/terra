# Herdeiros do Juramento

Simulador medieval de grande estratégia para navegador. A implementação atual é um protótipo da Fase 1, centrado na exploração do mapa; o escopo integral está em [docs/GDD.md](docs/GDD.md) e o estado real em [PROGRESS.md](PROGRESS.md).

## Executar

```sh
npm install
npm run dev
```

Abra o endereço local exibido pelo Vite. Os salvamentos ficam no IndexedDB do navegador.

## Verificar

```sh
npm test
npm run test:ui
npm run build
```
